# v0.2.0

## Highlights

- PostgreSQL + pgvector persistence with Alembic migrations
- Async ingest pipeline using Redis, Celery Worker and Beat
- Idempotent reindex, retry, cancel and stale-task recovery
- Pluggable rerankers: none, heuristic, LLM and local BGE
- Frozen synthetic retrieval benchmark with 152 cases
- Valid zero-fallback BGE test result
- SSE answer streaming with citation validation, token usage and generation traces
- Request IDs, structured request logs and CI automation

## Known Limitations

- Benchmark questions are synthetic template variants, not production traffic
- Local BGE compute and electricity cost are not monetized
- LLM reranker evaluation remains invalid due upstream rate limiting
- Uploaded source bytes are stored in PostgreSQL; object storage is still future work
